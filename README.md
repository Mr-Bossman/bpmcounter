# BPM Counter

A browser BPM counter with audio visualization.

## Features

- **Tap BPM** -  tap measure BPM
- **Auto BPM detection** - uses low-frequency band to find beats automatically
- **Full-screen oscilloscope**
  - **3-Band** - low (blue), mid (orange), and high (white) frequency bands
  - **RGB** - band energy mapped to low (red), mid (green), and high (blue) channels
  - **Blue** - intensity based waveform

## Usage

Open `index.html` in a browser or visit the [GitHub Pages site](https:///mr-bossman.github.io/bpmcounter).
